# XI Materials Audit Pack

Created from the user-supplied XI bundle and the screenshot supplied in the same conversation.

## Purpose

This package preserves the raw input, exposes the readable source files, expands the Prism design pack for inspection, and adds a factual audit manifest. It does **not** declare a canonical architecture.

## Layout

- `00_raw/original_user_bundle.zip` — untouched user-supplied ZIP. This is the provenance anchor.
- `00_raw/context_screenshot.png` — user-supplied screenshot from the same handoff.
- `01_materials/` — readable files extracted from the original ZIP, excluding Python bytecode caches only. No source file content was edited.
- `02_prism_expanded/` — expansion of `xiPrism_design_pack (2).zip` for convenient inspection.
- `03_audit/` — inventory, hashes, duplicate notes, Python parse checks, and a neutral Pro handoff prompt.

The original ZIP contains 29 ZIP entries. It includes source/design material for:

The original ZIP also contains compiled `__pycache__/*.pyc` files. Those remain preserved in `00_raw/original_user_bundle.zip` but are omitted from `01_materials/` because they are generated bytecode, not source.
